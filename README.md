# Практическая работа №4 — АС кадрового агентства

## Что внутри
- `main.py` — демонстрационная консольная программа на Python с классами соискателя, работодателя, вакансии, подбора и агентства.
- `Отчет по практической работе 4.docx` — отчёт со схемами, анализом предметной области и описанием ООП-модели.

Программа запускается без установки сторонних библиотек и хранит демонстрационные данные в памяти до завершения работы.

## Как открыть и запустить
1. Скачайте и распакуйте ZIP в обычную папку, например «Документы».
2. Откройте **PyCharm**. Выберите **File → Open** (Файл → Открыть) и укажите папку `Практическая работа 4`.
3. Откройте файл `main.py` в списке файлов слева.
4. Нажмите зелёный треугольник **Run** возле `main()` (или правой кнопкой по файлу → **Run 'main'**).
5. В появившейся консоли введите `1`, чтобы посмотреть соискателей; `2` — вакансии; `3` — подобрать вакансии. Для проверки подбора введите ID `1` или `2`.
6. Чтобы зарегистрировать результат, введите `4`, затем ID соискателя и подходящей вакансии. Выйдите командой `0`.

### Если запускаете через Терминал macOS
1. Откройте приложение **Терминал**.
2. Перейдите в распакованную папку командой `cd `, затем перетащите папку `Практическая работа 4` в окно Терминала и нажмите Enter.
3. Запустите `python3 main.py`.
4. Выполняйте команды по меню. Выйти можно командой `0`.

## Демонстрационный сценарий
Выберите `3`, введите ID соискателя `1` — программа покажет вакансию Python-разработчика. Затем выберите `4`, введите `1` и `1`: будет зарегистрирован подбор со статусом «Предложена».

Данные приложения учебные и не сохраняются после закрытия программы.
